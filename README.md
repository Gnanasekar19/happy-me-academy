# Happy Me Academy — source code

Source exported from the selected Happy Me Academy Sites project.
Commit: 2d981c1abaf861fd08bd93d18f85349349b053fe

## Run locally
1. Extract this ZIP.
2. Open the Happy_Me_Academy folder in VS Code.
3. Use Live Server on dist/index.html, or run:
   python -m http.server 8000 --directory dist
4. Open http://localhost:8000 in your browser.

No npm install or build is required for the current static website.

## Files
- dist/index.html: page markup
- dist/style.css: styles and responsive layouts
- dist/*.js: interactions, programs, gallery, and reviews
- dist/assets/: images and videos
- *.py: original project maintenance scripts; these are not needed to run the site
- .openai/hosting.json: original Sites hosting configuration

For static hosting, upload the CONTENTS of dist to the hosting root.
Historical deployment archives and Git history are omitted. Application files are unchanged.
This export is from the selected Sites project, not a separate GitHub repository.
