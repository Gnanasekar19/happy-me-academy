Happy Me Academy — Complete Website Source Code

Latest published version: 11

HOW TO OPEN
1. Extract this ZIP file.
2. Open index.html in your browser.
   You can also open this folder in VS Code and use Live Server.

FILES
index.html          Page structure and footer
style.css           Desktop and mobile styles
app.js              Page content and interactions
program-details.js  Full descriptions for all 17 programs and standalone common policies
reviews-data.js     Parent reviews
assets/             Website images and logos

No installation or build step is required. This is a static HTML/CSS/JavaScript website.
Keep these files and the assets folder together. Upload the contents of this folder to a static web host to publish.

The enquiry form opens an email draft in the visitor's email app; it does not store enquiries in a database or send them automatically.
